Le jeu s'appelle "Masquez les tous".
Avec une musique d'Alexis Lumière et un asset graphique d'Anna.
---
les carrés représentent des gens
les gens en bonne santé sont gris
les malades sont jaunes
les masqués sont rouges
les malades masqués sont oranges
les nombres des différentes catégories sont à gauche
Le jeu se joue en différentes manches
numéro de manche en blanc à gauche
au début de chaque manche, les carrés sont tous gris sauf un patient zéro jaune.
le but est de faire tomber le nombre de malades non masqués à 0.
Si le nombre atteint 200, vous avez perdu la manche.
Si vous gagnez la manche, vous passez immédiatement à la manche suivante qui est un petit peu plus difficile.
On finit toujours par perdre, comme à Tétris.
Mais comme dans Dwarf Fortress, perdre c'est rigolo!
